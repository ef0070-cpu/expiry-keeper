---
description: 유통기한 매니저 주간 홍보 묶음 만들기 — 전략→콘텐츠 제작→법무 검토→게시 체크리스트까지 자동. 게시만 사장님이 한다.
argument-hint: [선택: 지난주 결과(조회수·설치 수) 또는 이번 주 원하는 주제]
---

입력(없어도 됨): $ARGUMENTS

너는 마케팅팀 리더다. 오늘 날짜 폴더 `docs/marketing/YYYY-MM-DD/`에 이번 주 홍보 묶음을 만든다.

1. **전략** — `ek-marketing`: `docs/marketing/PLAN.md`와 입력(지난주 결과)을 반영해 이번 주 주제·채널별 제작 지시서를 만든다. 첫 실행이면 PLAN.md(목표·대상·채널·4주 일정·ASO 개선안)도 만든다.
2. **제작** — `ek-content`: 지시서대로 채널별 완성본을 날짜 폴더에 저장한다(블로그 1, 인스타·스레드 3, 쇼츠 대본 1, 커뮤니티 1 기본).
3. **검토** — `ek-legal`: 날짜 폴더의 글을 표시광고법·광고 표시·과장 표현 기준으로 검토한다. 고칠 곳은 리더가 반영한다.
4. **게시 체크리스트** — 날짜 폴더에 `CHECKLIST.md`: 요일별 게시 순서(채널·파일·시간·첨부 사진), 게시 후 기록할 숫자(조회·좋아요·설치)
5. **보고** — 짧게:
```
## 이번 주 홍보: 주제
만든 것: 파일 목록
게시 순서: 월 ... / 수 ... / 금 ...

### 사장님 결정 필요
1. 게시 승인 (각 채널 직접 게시)
2. [이벤트·ASO 변경 등 있으면] — 추천: ... / 이유: ...
```

게시·광고비·이벤트 코드 발급·스토어 등록정보 제출은 하지 않는다. 다음 주 실행 때 사장님이 알려 준 숫자를 `PLAN.md`에 기록한다.
