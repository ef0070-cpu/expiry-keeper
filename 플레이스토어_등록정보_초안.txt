[유통기한 지킴이] Play 스토어 등록정보 초안
(Play Console에 그대로 복사해서 쓰시고, 톤/문구는 자유롭게 다듬으세요)

────────────────────────────────
1. 짧은 설명 (최대 80자)
────────────────────────────────
유통기한을 한눈에, 알림으로 놓치지 않는 냉장고 재고 관리 앱

────────────────────────────────
2. 전체 설명 (최대 4,000자)
────────────────────────────────
냉장고 속 식품, 유통기한을 놓쳐서 버린 적 있으신가요?
유통기한 지킴이는 바코드 한 번 스캔으로 상품을 등록하고, 알림으로 유통기한을 미리 알려주는 재고 관리 앱입니다.

■ 이런 분께 추천해요
- 냉장고 정리가 늘 골칫거리인 분
- 유통기한을 깜빡해서 식품을 버려본 적 있는 분
- 소매점에서 상품 유통기한을 관리해야 하는 분

■ 주요 기능
- 바코드 스캔 자동 등록: 바코드만 스캔하면 상품명과 사진을 자동으로 찾아드려요
- D-day 대시보드: 유통기한이 임박한 순서로 한눈에 정리
- 맞춤 알림: 알림 횟수(1~7회)와 시간을 직접 설정
- 캘린더 보기: 일/월/년 단위로 유통기한을 달력에서 확인
- 소진·폐기 기록 및 통계: 얼마나 알뜰하게 소비했는지 월별로 확인
- 레시피 추천: 임박한 재료로 만들 수 있는 요리를 추천 (가정용 모드)
- 가족/팀 공유: 초대 코드로 가족이나 팀원과 재고를 함께 관리
- 가정용 · 소매점용 모드: 사용 목적에 맞게 화면 구성이 달라져요

■ 이렇게 사용하세요
1. 구글 계정으로 로그인
2. 바코드를 스캔하거나 직접 상품을 등록
3. 유통기한이 다가오면 알림을 받고, 소진하거나 폐기 처리
4. 통계와 레시피로 낭비 없는 소비 습관 만들기

유통기한 지킴이와 함께 냉장고 속 식품을 끝까지 알뜰하게 사용해보세요.

4. 콘텐츠 등급 관련
────────────────────────────────
폭력적/선정적 콘텐츠 없음, 사용자 생성 콘텐츠(상품명 등)만 존재 → 설문 진행 시 "전체 이용가" 방향으로 응답하면 됩니다.
(정확한 등급은 Play Console의 콘텐츠 등급 설문에서 실제로 답변해야 확정됩니다 — 아래 데이터 항목 참고해서 진행하세요.)

5. 데이터 보안(Data Safety) 섹션 답변 초안
────────────────────────────────
※ 아래는 코드 기준으로 정리한 초안입니다. Play Console 설문 문구가 바뀔 수 있으니 실제 화면 문구에 맞춰 확인하며 체크하세요.

수집하는 데이터:
- 이메일 주소 (Google 로그인 계정 식별용) — 필수
- 사진 (상품 등록 시 사용자가 직접 촬영/선택한 상품 사진) — 선택
- 앱 활동/사용자 콘텐츠 (등록한 상품명, 카테고리, 유통기한 등 재고 데이터) — 필수

수집 목적:
- 앱 기능 제공 (재고 관리, 알림)
- 계정 관리 (로그인)

제3자 공유 여부:
- 사용자 데이터를 광고/마케팅 목적으로 제3자와 공유하지 않음
- 단, 바코드 조회 시 바코드 번호가 식품안전나라 Open API로 전달됨 (제품 정보 조회 목적, 서버(Edge Function) 경유)
- 상품명 이미지 검색 시 상품명 키워드가 네이버/카카오 검색 API로 전달됨 (이미지 검색 목적, 서버 경유)
→ Play 설문에서 "제3자와 데이터 공유"에 해당할 수 있으니, 설문 문항을 보면서 "예/목적: 앱 기능"으로 답변하는 걸 권장합니다.

보안:
- 전송 중 암호화: 예 (HTTPS)
- 사용자의 데이터 삭제 요청 가능: 예 (설정 > 회원 탈퇴 기능으로 계정 및 연관 데이터 즉시 삭제)
