## 1-2. 가정용 광고 추가 의견 (2026-10-02)

- 원칙: "광고 제거 2,900원"을 사게 만드는 건 광고 양이 아니라 **적당히 거슬리는 지점 1개**. 과하면 결제 전에 앱을 지운다.
- 권장: 애드몹 **전면 광고 1종만** 추가 — 상품 저장 직후에만, 하루 1회, 설치 후 3일간 없음, 스캔·알림 열기 중엔 절대 없음. 전면 광고 닫을 때 "광고 없이 쓰기 2,900원" 안내.
- **확정(옵션 A)**: 위 조건의 전면 광고 1종 추가. **유료 결제(평생 2,900원) 시 배너·전면 광고 모두 자동 제거**(테스터 평생 무료 포함).
- 비권장: 쿠팡 배너 광고 추가 — 앱 안 사용 가능 여부 문의 답변 전이고, 평생 결제로 "광고 제거"를 팔면 쿠팡 배너도 같이 꺼야 함.

## 1-5. 소매 단톡방 홍보용 매장용 무료 이벤트 (2026-10-02 검토)

- 현재 코드: 결제·유료 권한·쿠폰 관련 코드 **없음**.
- 권장 방식: **앱 자체 이벤트 코드** — 설정에서 코드 입력 → 서버에 "매장용 유료 기능 ○월 ○일까지" 기록. 카드 등록·자동 결제 없음, 기간 끝나면 무료 한도로 돌아가고 구독 안내.
  - 테스터 평생 무료와 같은 구조(유료 권한 + 종료일, 평생은 종료일 없음)라 결제 기능 만들 때 같이 만든다.
  - 남용 방지: 코드별 최대 사용 인원, 입력 마감일, 계정당 1회.
  - 코드는 무료 배포만. 코드를 판매하면 구글 결제 정책 위반.
- 비권장: 구글 플레이 구독 무료 체험 — 카드 등록 필요(참여율↓), 끝나면 자동 유료 전환 → 개정 전자상거래법상 전환 전 고지·동의 의무, 자동 결제 불만 위험.
- 기간: 3개월 권장(6개월은 구독 전환 3개월 늦어짐 → 전환 1명당 약 9,000원 손해).
- **확정(옵션 B)**: 이벤트 코드 입력 시 **매장용 유료 기능 6개월 무료**. 종료 7일 전 안내 알림. 결제 기능 개발 때 함께 구현.
- 선착순 한정 배포 → **1인 1코드(코드마다 1회만 사용)**. 공용 코드 1개는 다른 방으로 퍼지면 막을 수 없어 쓰지 않는다.
  - 형식: **의미 없는 무작위 12자리** `XXXX-XXXX-XXXX` (예: `K7QX-M4TP-9WHZ`) — 영문 대문자+숫자 중 헷갈리는 0/O·1/I/L 뺀 31종, 경우의 수 약 79경. 보안 난수 생성기로 만들고 서버엔 코드 원문 대신 암호화 지문(해시)만 저장(서버 유출돼도 코드 노출 안 됨). 특수문자는 안 씀(휴대폰 키보드 전환·메신저 자동 변환으로 입력 실패 잦음, 보안 강도는 길이로 확보). 묶음 이름(예: 단톡방 무료 이용 이벤트)·입력 마감일 포함.
  - 서버: 코드 표(코드·묶음·개월 수·사용 계정·사용 시각·마감일), 사용 처리는 "아직 안 쓴 코드만" 한 번에 바꾸는 방식이라 두 명이 동시에 넣어도 1명만 성공.
  - 계정당 이벤트 코드 1번만, 코드 입력 화면은 5번 틀리면 잠시 막기(무작위 대입 방지).
  - 코드 목록은 엑셀로 뽑아 사장님께 전달, 사용 현황(누가 언제 썼는지)도 확인 가능.
  - **확정**: 이벤트 이름 `단톡방 무료 이용 이벤트` **100개**, 배포는 **신청자에게 개인 메시지로 1개씩**(옵션 A). 엑셀에 "보낸 사람" 칸을 둬 사장님이 누구에게 줬는지 적을 수 있게.
- 출시 직전 점검 추가: 앱 전체 오픈소스(React Native·Expo 등 MIT·Apache) 저작권 고지 화면 — 설정에 "오픈소스 라이선스" 메뉴.
