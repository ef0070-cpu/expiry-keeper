# 유통기한 지킴이 — 수익 모델 결정 사항

최종 갱신: 2026-10-02 (사장님 확정)

## 1. 확정 결정

| 항목 | 결정 |
|---|---|
| 앱 이름 | 유통기한 지킴이 |
| 매장용 광고 | 넣지 않음 |
| 가정용 | 애드몹 배너 노출, **평생 결제 2,900원 → 배너 제거** (쿠팡 구매 카드는 기능이므로 유지, 설정에서 끄기 가능) |
| 매장용 | **월 구독 3,900원** |
| 테스터 | 현재 테스터 인원 **평생 무료(가정용 광고 제거 + 매장용 유료 기능 전부)** |
| 법무 점검 | 출시 직전 1회 — 환불·자동결제 해지 안내, 스토어 설명 문구 |

### 매장용 무료 한도

| 기능 | 무료 | 구독 | 세는 기준 |
|---|---|---|---|
| 유통기한 상품 등록 | 30개 | 무제한 | **지금 관리 중인 상품만** (판매·폐기 처리분 제외) |
| 팀 공유 | 혼자(본인 1명) | 팀원 초대 | 초대 버튼 → 구독 안내 |
| 발주서 작성 | 5개 | 무제한 | 매월 1일 초기화 |
| 가격표 생성 | 5개 | 무제한 | 매월 1일 초기화 |
| 상품별 알림 횟수 | 최대 2회 | 최대 7회 | 기존 설정(`settings.ts` count 1~7) 상한만 제한 |

한도 공통 원칙: 넘어도 **기존 데이터는 그대로 보이고 알림도 계속 감**. 막는 건 "새로 추가"뿐.

### 미결

- 할인 표시 방식: 옵션 A(출시 기념가 + 인상 날짜 확정) / 옵션 B(본전 회수 문구만). 날짜가 정해지지 않아 아래 초안은 B 기준.
- 테스터 명단(로그인 이메일) — 받으면 서버 평생 무료 목록에 등록.

## 2. 구현 메모

- 결제: 평생 결제(일회성 상품)와 매장용 구독을 같은 결제 모듈로. **구매 복원** 필수.
- 테스터 평생 무료: 플레이 프로모션 코드는 구독엔 평생 적용 불가 → 서버(Supabase)에 평생 무료 사용자 목록을 두고 앱이 확인.
- 9,900원 등 판매한 적 없는 가격을 할인 전 가격으로 표시 금지(표시광고법, 플레이 메타데이터 정책).

## 3. 법무 점검용 문구 초안 (출시 직전 점검 대상)

> 아래는 초안이다. 출시 직전 법무 점검에서 최신 법령·플레이 정책과 대조해 확정한다.

### 3-1. 결제 화면 — 가정용 평생 결제

- 2,900원(부가세 포함), 한 번 결제로 광고가 영구 제거됩니다.
- 같은 구글 계정이면 휴대폰을 바꿔도 [구매 복원]으로 다시 적용됩니다.
- 결제 즉시 광고 제거가 적용되어, 구매 후 7일 이내라도 **이용을 시작한 경우 청약철회가 제한될 수 있습니다**. 결제 후 48시간 이내에는 구글 플레이에서 직접 환불 요청할 수 있습니다.

### 3-2. 결제 화면 — 매장용 월 구독

- 월 3,900원(부가세 포함), **매월 같은 날 자동 결제**됩니다.
- 해지: 구글 플레이 → 결제 및 정기 결제 → 정기 결제 → 유통기한 지킴이 → 정기 결제 취소. 앱 설정에도 같은 경로로 가는 [구독 관리] 버튼을 둡니다.
- 해지해도 이미 결제한 기간이 끝날 때까지 유료 기능을 쓸 수 있습니다.
- 가격이 오르면 결제일 30일 전까지 알리고 동의를 받습니다. 동의하지 않으면 자동 결제되지 않습니다.
- 구독이 끝나도 등록한 상품·발주서·가격표는 지워지지 않습니다(새로 추가만 무료 한도 적용).

### 3-3. 스토어 설명 (가격 부분)

> 버리는 우유 한 팩만 막아도 본전!
> 가정용은 무료로 쓰고, 광고가 싫다면 **평생 2,900원** 한 번이면 끝.
> 매장용은 상품 30개까지 무료, 더 필요하면 월 3,900원.

- [ ] 전자상거래법 청약철회 제한 고지(디지털콘텐츠 이용 개시 전 명확 고지)
