## 2. v31에 들어갈 변경 (커밋 완료, 빌드 대기)

모두 `src/app/product-form.tsx`(상품 등록·수정 화면) 중심.

- **수량 직접 입력** — 숫자 칸을 누르면 숫자 키패드(1~9999). +/− 그대로 (`d7b85a0`)
- **날짜 표기 순서** — 유통기한 제목 옆 `[년/월/일 ▾]` 하나로 선택(일/월/년·월/일/년). 이 상품에만 적용, 기본값은 설정 화면 값. 자동·사진 인식과 직접 입력 모두에 적용 (`9f4c2da` → `93dbb43`, `d6cbba1`)
- **바코드 국가번호 → 날짜 순서 자동 추천** — `src/lib/date-ocr.ts` `dateOrderFromBarcode()`. 해외면 유통기한 아래 한 줄 안내("독일 제품 바코드예요(일/월/년). 다르면 바꿔 주세요."). 한계: 앞자리는 생산국이 아니라 **바코드 등록국** → 강제 아닌 추천
- **중국 제품 제조일+기간 팝업** — 중국 바코드(690~699)에서 [자동 인식]/[사진 인식]을 누르면 "중국 제품입니다" 확인 → [예]면 읽은 날짜를 **제조일**로 팝업에 넣음. 팝업: 제조일(입력·달력·오늘), 기간 숫자+[일|개월], 빠른 선택 30·60·90·180일·6·12개월, 요일 포함 계산 결과, [취소][확인(적용)]. 인라인 블록·별도 버튼은 사장님 요청으로 **삭제함** (`e963215`, `f1747cb`)
  - 계산 기준 **"기간 끝나기 하루 전"** (`src/lib/dates.ts` `expiryFromManufacture`) — 사장님 시안은 딱 그날이었음. 바꾸려면 마지막 `addDays(..., -1)` 한 줄
  - 바코드별 보존기간 기억: `src/lib/mfg-period.ts` (폰 안 AsyncStorage, 팀 공유 안 함)
- **붙은 8자리 날짜 인식** — `20260310`, `2026031014:22` (`COMPACT_RE`, 바코드·긴 로트 번호는 제외)
- **바코드 다시 촬영·직접 수정** — 상품명 아래 바코드 번호(밑줄+빨간 연필)를 누름. 수정 중인 상품은 번호만 바뀌고 입력 내용 유지(`/scan?mode=pick` + `src/lib/scan-pick.ts` 재사용) (`d7f0597`)
- **새 버전 안내 창** — 실행 시 서버 `app_config.latest_version_code`보다 낮으면 `update_notes`를 보여 주고 [업데이트]→플레이스토어. `min_version_code` 미만이면 "나중에" 없음. `src/lib/app-update.ts`, SQL `supabase/migration-app-update.sql`(**실행 필요**). 스토어 공개 확인 **후에** 값 변경
- **새 카테고리 입력칸 글자 잘림 수정** (`c14e0bb`)
- **새 앱 아이콘** — 로봇+"유통기한 매니저", 흰 배경. 적응형 전경/배경/테마 단색/시작 화면(크기 200)/파비콘 (`22b3c2b`)
- (참고) 홈 화면 카드 축소·상단 아이콘 확대(`bff370f`)는 v30에 이미 포함

**폰에서 직접 확인한 것**: 날짜 순서 버튼·안내 줄, 도구 줄 한 줄 배치, 바코드 표시, 카테고리 입력칸. **아직 직접 안 눌러 본 것**: 중국 확인 창→팝업 흐름, 바코드 다시 촬영, 수량 직접 입력, 붙은 날짜 사진 인식 → v31 전에 개발용 앱으로 한 번 확인 권장

## 3. 요금·유료 기능 (결정 사항)

자세한 근거는 `docs/monetization.md`.

| | 무료 | 유료 |
|---|---|---|
| 가정용 | 기능 무제한, 광고(배너 + 전면 광고 하루 1회·설치 3일 후) | **평생 1,900원** `ad_free_lifetime` → 광고 제거 |
| 매장용 | (스위치 켜면) 상품 50개·발주서/가격표 월 5회(쓸 때마다 남은 횟수 안내창)·팀 불가, 하단 배너 광고 | **월 3,900원** `retail_monthly` → 무제한·팀·광고 없음 |

- 매장 유료(구독·이벤트 코드·테스터·팀장 권한 상속)면 **가정용 광고 제거도 자동** (`429a886`)
- 테스터 26명(서버 `tester_emails`) = 가정·매장 모두 평생 무료. 명단 원본 `.private/testers.sql` (git 제외)
- 가격은 앱이 아니라 **플레이 콘솔 상품 가격**을 그대로 표시 → 가격 변경에 빌드 불필요
- 검토 의견: 매장 3,900원은 경쟁(샵솔 월 18,000원~, 박스히어로 월 $30)보다 매우 쌈. 인상 계획 있으면 처음부터 4,900원 권장. 미결

## 4. 사장님이 하실 일 (순서대로)

1. **플레이 콘솔 v30 출시 마무리** — 프로덕션·내부 테스트에서 "권한 없이 출시" → 저장 및 출시. ("선언 업데이트"는 누르지 말 것)
2. **스토어 등록정보 검토 결과 확인** (10/8 제출, 수 시간~며칠)
3. **결제 상품 등록** — 수익 창출 → 인앱 상품 `ad_free_lifetime` 1,900원 / 정기 결제 `retail_monthly` 월 3,900원
4. **결제 확인 서버 준비** — 구글 클라우드 서비스 계정 만들기 → 플레이 콘솔 권한 부여 → 키를 Supabase 비밀값으로 → `verify-purchase` 함수 배포 (**아직 배포 안 됨** — 10/9 확인: 배포된 함수는 barcode-lookup·image-search·delete-account 셋뿐)
5. **라이선스 테스트 계정 등록** 후 내부 테스트판으로 결제·복원·해지 시험
6. **애드몹 전면 광고 단위 만들기** → ID를 `src/lib/interstitial.ts`의 `INTERSTITIAL_UNIT_ID`에 (지금 빈 값이라 전면 광고 안 뜸, 배너는 뜸)
7. **v31 빌드 지시** (새 아이콘·2장 기능 반영)
8. 6~8주 지표 확인 후 매장 유료화 스위치 켤지 결정 (서버 `app_config` 값만 바꾸면 됨)

## 5. 개발·테스트 방법

- **폰 테스트(빌드 없이)**: 폴드 USB 연결·USB 디버깅 허용 → 개발용 앱 설치
  `adb install -r "%TEMP%\expiry-dev-e6ce0141.apk"` (versionCode 27 개발 클라이언트, 10/2 빌드 — 네이티브 모듈이 안 바뀌는 한 재사용 가능)
  → `npx expo start --dev-client --localhost --port 8081` → `adb reverse tcp:8081 tcp:8081`
  → `adb shell am start -a android.intent.action.VIEW -d "exp+expiry-keeper://expo-development-client/?url=http%3A%2F%2Flocalhost%3A8081"`
- 스토어용 빌드와 개발용 앱은 서명이 달라 **같이 설치 불가** (지우고 설치). 지금 폴드에는 **개발용 앱**이 깔려 있음 → 일상 사용은 플레이스토어판 재설치 필요
- **스토어 빌드를 폴드에 직접 깔아 확인**: `bundletool build-apks --connected-device` + 테스트 키 → `install-apks` (R8 관련 문제는 스토어 빌드에서만 보임 — v29 로그인 거부 원인이었음)
- 검사: `npx tsc --noEmit` (login.tsx 115행 기존 경고 1건은 무시), 자가검사 `npx tsx src/lib/*.selfcheck.ts`
- 화면 캡처: `adb exec-out screencap -p -d 4630947194243491972` (폴드 메인 화면 ID)
- 테스트 바코드: 나라별·중국 제품 테스트 HTML(JsBarcode)을 세션 임시 폴더에 만들어 PC 화면에 띄워 찍었음. 필요하면 다시 생성

## 6. 주의할 점 (겪은 문제)

- **빌드 전 반드시 사장님 승인** (무료 빌드 한정). 이름·아이콘 같은 네이티브 변경은 빌드해야만 반영
- **C 드라이브 공간** — 한때 0.11GB까지 떨어져 작업이 멈춤. 빌드·설치 전 여유 공간 확인
- node 스크립트로 코드 패치할 때 템플릿 문자열 안 `\d`, `\D`가 `d`, `D`로 깨지는 일이 두 번 있었음 → 정규식은 Edit 도구로 넣고 자가검사로 꼭 확인
- 플레이 콘솔: 아이콘·그래픽 교체 시 **삭제가 늦게 반영돼 2개가 되는 경우**가 있음(1개 이하 오류) / 저장 버튼이 화면 밖이면 **⋮ 메뉴 → 저장** / "임시보관함에 저장"만으론 게시 개요에 안 올라감 → **다음 → 저장**까지 해야 함 / 새 애셋을 넣으면 AI 생성 라벨 창에서 그 애셋을 다시 체크해야 함
- 사장님 테스트 팀 계정에 발주 상품이 중복으로 쌓였던 문제 — v25 재설치 때문(중복 방지 수정 이전 빌드). 10/6 서버 정리 완료(5,631→3,200개). 남은 이름 중복 1건 "포도젤로바"(바코드 있는 것/없는 것)
