- **마이크**: 검색창 안 아이콘(톡=화면 마이크 켜기/끄기, 길게=말하기), 둥근 마이크는 누른 채 끌어 위치 이동(이 기기에 저장, 기본은 가로·세로 74% 지점), 듣기가 안 끝나는 경우 방지(손 뗀 뒤 2.5초·최대 12초·백그라운드 중단), 두 마이크의 이벤트 혼선 방지

- **발주**: 공유 창이 닫혀도 바로 이력을 저장하지 않고 "발주서를 보내셨나요?"에서 "보냈어요"를 눌러야 이력·장바구니 비움·월 사용량 처리. 전송 글에 납품 희망일·배송 메모 포함(미리보기도 같음), 배송 메모 입력창이 키보드에 가리지 않음, 빠른발주에서도 📅 이력 버튼

- **새 빌드 주의**: 네이티브 변경 없음(음성 인식 모듈은 v34에 이미 있음)
- **알려진 한계**: 서버에서 지운 상품이 폰에 남는 문제는 정리 기능 없이 남음(시도한 "서버에 없는 상품 정리"는 시험 중 폰 상품 43건이 실수로 지워져 제거). 실제 말하기 인식 품질은 폰에서 직접 확인 필요

  ```sql
  select case when lower(u.email) in (select lower(email) from public.tester_emails) then 'tester' else 'general' end as kind,
   count(*) as users,
   count(*) filter (where exists (select 1 from public.products p where p.user_id = u.id)) as has_products,
   count(*) filter (where u.last_sign_in_at > now() - interval '7 days') as signin_7d,
   count(*) filter (where u.created_at > now() - interval '7 days') as new_7d
  from auth.users u group by 1 order by 1;
  ```
