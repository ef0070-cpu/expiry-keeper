# 홍보 문구 규칙 (브랜드 보이스)

> 사장님 지시(2026-10-21). 모든 홍보 원고·카드 이미지·게시 계획에 적용. ek-marketing·ek-content·ek-legal·ek-design·ek-promo-lead는 작업 전에 이 문서를 읽는다. 다른 문서와 다르면 이 문서가 우선.

## 1. 우리는 앱 제작사다
- 화자는 **"유통기한 매니저"(브랜드)** 또는 **"유통기한 매니저 팀"**. 개인 개발자 1인칭을 쓰지 않는다.
- 금지: "제가 직접 만든", "직접 만들었어요", "제 앱", "혼자 만든", "개발자인 제가", "써 보시고 의견 주시면 반영할게요"처럼 개인 부탁조
- 대신: "유통기한 매니저는 ~를 지원합니다", "~할 수 있어요", 의견 요청은 "댓글로 알려 주세요" 같은 서비스 안내조

## 2. 무료·가격을 약속하지 않는다 (유료화 대비)
- 금지: "무료", "무료 앱", "전부 무료", "평생 무료", "공짜", "무제한", "지금은 무료(나중에 유료)" 같은 가격 안내 문구 — 원고·카드·해시태그 모두
- 가격·요금 질문이 오면 "앱 안 안내를 참고해 주세요" 수준으로만 답한다
- 혜택은 가격이 아니라 **기능·편의**로 말한다(시간 절약 수치·폐기율 같은 효과 숫자는 여전히 금지)

## 3. 광고 표시
- 브랜드 공식 계정(인스타·스레드·블로그·유튜브)에 올리는 글은 브랜드가 올리는 홍보라, 별도 "개발자 본인" 표시 대신 계정 이름이 그 역할을 한다.
- 커뮤니티(카페)·지인 단톡처럼 개인 계정으로 올릴 때는 첫 줄에 **"유통기한 매니저 운영팀입니다"**처럼 제작사임을 밝힌다(추천·보증 표시 원칙 — 숨기지 않기).
- 협찬·대가가 있는 글은 지금처럼 "광고" 표시.

## 4. 톤
- 존댓말, 짧고 확신 있게. 과장·최상급("최고", "1위", "끝판왕") 금지
- 마무리 행동 유도: "플레이스토어에서 '유통기한 매니저'를 검색해 보세요" / "프로필 링크에서 받을 수 있어요"

### 4-1. 채널별 링크·태그 규칙 (2026-10-30 사장님 결정)
- **스레드**: 본문 링크가 눌리므로 마무리 행동 유도를 **설치 링크 하나**로 한다(검색 문구와 같이 쓰지 않는다). 링크는 그 묶음의 캠페인 코드(UTM) 링크 — `utm_source=threads&utm_medium=post&utm_campaign=<그 주 코드>`.
- **스레드 태그**: 해시태그를 여러 개 붙이지 않는다. 글당 **주제 태그 1개**만 쓴다(첫 번째만 동작). 이름은 글 주제에 맞게(예: `냉장고파먹기`), 가격·무료·최상급 단어 금지.
- **인스타그램**: 캡션의 링크는 눌리지 않는다(확인함). 캡션에는 주소를 넣지 않고 마무리를 "플레이스토어에서 '유통기한 매니저'를 검색해 보세요"로 한다. 눌리는 링크는 **프로필 링크**뿐이므로 그 주 캠페인 코드(UTM) 링크로 교체한다(모바일 앱에서만 변경 가능). 해시태그는 게시물당 **5개 이하**.
- **인스타 해시태그(매장·점주 대상 글)**: `#아이스크림할인점` `#무인아이스크림할인점`을 앞에 두고, 나머지 3개는 글 주제(예: `#원가계산` `#매장운영` `#유통기한매니저`)로 채운다. 가정용 글은 `#냉장고파먹기` 등 주제 태그로 5개를 채운다.
- **네이버 블로그 태그**: 글 끝에 태그 **10개 안팎**(에디터 "태그 입력" 칸에 단어만, # 없이). 점주 대상 글은 `아이스크림할인점` `무인아이스크림할인점` `무인점포`를 앞에 두고, 글 주제 키워드(발주관리·발주서·원가계산 등)와 `유통기한매니저`로 채운다. 가격·무료·최상급 단어와 글에 없는 기능(예: 버전 B에서는 가격표) 태그 금지. 태그도 팀장 심사 대상이다.
- 공개 계정 글은 올린 뒤 15분 안에만 스레드에서 수정할 수 있다. 문구 확정 전에는 올리지 않는다.

### 4-2. 댓글 응대 규칙 (자동 답글, 2026-10-30 사장님 결정)
- **정해진 문구(템플릿)로만 답한다.** 즉석 생성 문장 금지 — 잘못된 약속·가격 안내가 나가지 않게. 템플릿은 `scripts/reply-promo.mjs`에 있고, 바꿀 때는 이 장의 규칙을 먼저 지킨다.
- 화자는 "유통기한 매니저 운영팀". 개인 1인칭("제가")·"직접 만든"·이모지 남발 금지. 존댓말, 두 문장 이내.
- **가격·무료·구독·결제 질문**: "가격과 이용 조건은 앱 안 안내를 참고해 주세요." 외에 금액·무료 여부·계획을 말하지 않는다.
- **기능 요청·불편·오류 제보**: 감사 + "개선에 참고하겠습니다." 수준. 일정·반영 약속 금지.
- **칭찬·감사**: 감사 한 줄.
- **답하지 않는 것(기록만 남기고 사장님이 직접 본다)**: 분류되지 않는 댓글, 링크·연락처가 든 댓글, 욕설·분쟁·법적 언급, 개인정보 요청, 타사 비교·비방, 300자 넘는 댓글.
- 같은 댓글에는 한 번만 답한다. 계정 자신의 글·답글에는 답하지 않는다. 한 번 실행에 최대 5건.
- 처음에는 미리보기(`node scripts/reply-promo.mjs`)로 답할 내용을 확인하고, 사장님이 `--live`를 켜기 전에는 실제 답글을 달지 않는다.

## 고쳐 쓰기 예
| 쓰지 않음 | 이렇게 |
|---|---|
| 제가 직접 만든 무료 앱(광고 포함)이에요 | 플레이스토어에서 '유통기한 매니저'를 검색해 보세요 |
| 2026년 11월 기준 매장 기능 무료예요 | (문장 삭제) |
| 써 보시고 불편한 점 알려 주세요 | 필요한 기능이 있으면 댓글로 알려 주세요 |
| 안녕하세요, 앱을 직접 만든 개발자입니다 | 안녕하세요, 유통기한 매니저 운영팀입니다 |

## 5. 문장 품질 — 개성 없는 글 거르기 (2026-10-28 추가)
- **바꿔 쓰기 시험**: 앱 이름만 다른 앱으로 바꿔도 그대로 통하는 문장은 지우고, 냉동고 앞·알바와 점검 분담·발주 같은 **구체적인 장면**으로 다시 쓴다
- 쓰지 않는 말
  - 빈 칭찬: "혁신적", "획기적", "압도적", "완벽한"
  - 근거 없는 긴박감: "지금 안 하면", "오늘만", "놓치지 마세요"
  - 막연한 행동 유도: "자세히 보기", "확인해 보세요"만 단독으로
  - 근거 없는 사회적 증거: "많은 사장님이 쓰고 계세요", "다들 선택한" (사용자 수·후기는 실제 확인된 것만, 출처와 함께)
  - 낚시: 제목·첫 줄이 약속한 내용이 본문에 없는 글
- 행동 유도는 글 하나에 **하나만**, 4장의 문구 중에서 고른다

## 6. 새 기능은 프로덕션 출시 뒤에만 (2026-10-28 추가)
- 홍보 글·카드·쇼츠 대본에는 **프로덕션 트랙에 출시된 기능**만 쓴다. 출시 여부는 `docs/HANDOFF.md` 1장(프로덕션 트랙)에서 확인한다
- 내부 테스트 중인 기능은 쓰지 않는다. 출시 시점이 불분명하면 쓰지 말고 "사장님 결정 필요"로 올린다
- 이유: 스토어에서 받을 수 없는 기능을 홍보하면 설치 직후 실망과 허위 표시 문제가 된다
