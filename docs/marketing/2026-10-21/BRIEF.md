## 1. 이번 주 주제

**발주·가격표, 폰 하나로** (PLAN의 "10분 컷"은 내부 이름으로만 씀 — 아래 이유)

- 매장(주): 냉동고 칸 순서대로 눌러 담는 **빠른발주** → 담은 목록을 **발주서로 카톡·문자 공유** → 같은 앱에서 **가격표** 만들어 이미지로 저장.
- 가정(보조): **"냉장고 파먹기"** — 7일 안에 써야 할 재료로 한식 레시피 추천.
- 목표(안): 설치 25명(매장 모드 8곳) — PLAN 1장 4주 100명을 주당으로 나눈 값. 1주차가 같은 주에 나가면 합산으로 본다.

### "10분 컷"을 공개 문구에 쓰지 않는 이유
- "10분이면 끝"은 **시간 효과를 숫자로 주장**하는 표현이다. 실제로 재 본 적이 없다(코드·문서 어디에도 측정 기록 없음). 1주차 법무 검토 기준(수치 효과 주장 금지, `LEGAL-REVIEW.md` 전체 판단·⑥)과 HANDOFF 6장 홍보 원칙에 걸린다.
- 대신: "냉동고 칸 순서대로 톡톡", "담은 목록 그대로 카톡으로", "가격표도 같은 앱에서". 시간을 말하고 싶으면 사장님이 직접 재 본 뒤 "제가 해 보니 ○분 걸렸어요(1인 측정)"처럼 개인 경험으로만 — 이 경우 `ek-legal` 검토.

### 2-2. 쓰지 말 것 (확인 못 했거나 사실과 다름)
- **확인 못 한 것은 쓰지 않는다.** 아래는 이번 확인에서 근거를 못 찾은 것들:
  - 발주서를 **엑셀·PDF 파일**로 만든다 / 거래처에 **자동 전송** / 거래처별 발주서 → 실제는 "글로 공유"만 확인
  - 가격표를 **프린터로 바로 인쇄** → 실제는 "이미지로 저장·공유"까지만 확인. "저장한 이미지를 인쇄하면 돼요"까지는 OK
  - POS 연동, 자동 재고 차감, 판매량 기반 자동 발주 추천
  - 레시피 **개수**(몇 가지) — 세지 않았으니 숫자 쓰지 않음
- "무제한" 금지: 유료화 후 무료 한도가 **발주서 공유·가격표 저장 각각 월 5회**로 정해져 있다(`docs/monetization.md` 22~23행, `src/app/premium.tsx`). 지금은 스위치가 꺼져 무료지만 "무제한으로 쓰세요"라고 쓰면 나중에 거짓이 된다.
- 기본 발주 상품 목록: "자주 파는 상품 목록이 들어 있어요"를 **장점으로 내세우지 않는다**(1주차 법무 ④ — 출처 정리 미해결). 빠른발주 장면에 상품 이름이 보이는 것 자체는 괜찮다.
- 레시피 화면의 **"부족 재료 → 쿠팡" 칩은 홍보물에 보여주지도, 언급하지도 않는다**(쿠팡 파트너스 실적 연동 — 홍보에 넣으면 경제적 이해관계 표시 문제가 생김, `ek-legal` 확인 전까지 제외). 캡처할 때 그 부분이 화면 밖이거나 잘리게.
- 아이스크림 날짜: 아이스크림류는 소비기한 대신 제조연월만 표시할 수 있다는 HANDOFF 6장 미확인 사항 → 이번 주는 발주 중심이라 "아이스크림 유통기한 알림"을 강조하지 않는다.
- v31 미검증 기능(수량 직접 입력, 중국 제품 팝업, 바코드 다시 촬영 등) 언급 금지.
