## 실행 검증 (npx tsx, 2026-11-05)
- `tileArt`: 초코바 🍫 / 딸기바 🍓 / 바닐라콘 🥛 / 커피 튜브 ☕ / 초코 컵 🍫 / 소다바 null(그림 없음). 이번 4종 화면(스캔·등록·홈·설정)은 사진 없는 상품의 회색 '사진 없음' 칸을 쓰므로 이모지 그림이 화면에 나오지 않는다. `tileArt`는 검색발주·빠른발주 카드용(order.tsx)이다.
- `ALERT_OFFSETS`+`ddayLabel`: 1회 D-DAY / 2회 D-DAY, D-1 / **3회 D-DAY, D-1, D-3** / 4회 …D-7 / 5회 …D-14 / 6회 …D-21 / 7회 …D-30. 화면은 3회.
- `ddayLabel`·`signalOf`(7일 이하 빨강, 30일 이하 주황, 그 위 초록)로 D-3 빨강·D-19 주황·D-45 초록 확인.
- `formatAlertTime`은 settings.tsx 안의 비공개 함수(406~410행)라 import할 수 없어 같은 코드를 그대로 옮겨 실행: (9,0) → '오전 9:00'. 기본값 2회·9시 0분은 `settings.ts:72`. 이번 화면은 횟수만 3회로 바꾼 상태.
