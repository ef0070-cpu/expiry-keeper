# 유통기한 매니저 홍보 계획 (PLAN)

> 마케팅팀 리더 관리 문서. 매주 실행 때 "주간 기록"에 이번 주 주제를 추가하고, 사장님이 알려 준 숫자를 채운다.
> 최초 작성: 2026-10-12 (출시 직후, 홍보 0 상태)

## 1. 목표
- 광고비 0원으로 **첫 설치 100명 → 1,000명**
- 6~8주 지표(설치·유지율·광고 노출)를 모아 매장 유료화 스위치(`paywall_enabled`) 결정 근거 만들기 (`docs/monetization.md`)
- 후기·평점은 **자연스러운 사용자 후기만** 모은다(가짜 후기·리뷰 조작 금지)

## 2. 대상
| 구분 | 누구 | 쓰는 말 | 핵심 가치 |
|---|---|---|---|
| 가정 | 냉장고 음식 버리는 게 아까운 주부·1인 가구·자취생 | "또 버렸네", "냉장고 정리" | 바코드·사진으로 쉬운 등록, 임박 알림, 레시피 추천 |
| 매장 | 편의점·마트·카페·식당 사장님 | "폐기", "발주", "재고" | 유통기한 관리, 발주서·가격표, 팀 공유 |

## 3. 채널 (무료만)
| 채널 | 역할 | 주기 |
|---|---|---|
| 네이버 블로그 | 검색 유입(오래 감) | 주 1 |
| 인스타그램·스레드 | 공감·저장·공유 | 주 3 |
| 유튜브 쇼츠(릴스 재사용) | 시연 영상 | 주 1 |
| 커뮤니티(홍보 허용 게시판만) | 첫 사용자·피드백 | 주 1 |
| 지인·단톡방 추천 | 초기 100명 | 수시 |

규칙: 도배·자동 게시·가짜 후기 금지. 커뮤니티는 게시판 규칙 확인 후 개발자 본인임을 밝힌다.

## 4. 4주 일정 (주제는 지난주와 겹치지 않게)
| 주 | 날짜(월) | 주제 | 핵심 기능 | 대상 |
|---|---|---|---|---|
| 1 | 10/12 | **냉장고 비우기 주간 — 버리기 전 마지막 점검** | 임박 알림, 달력, 레시피 추천 | 가정 |
| 2 | 10/19 | **바코드로 3초 등록 — 입력 귀찮아서 안 쓰던 분께** | 바코드 스캔, 사진 인식 | 가정 |
| 3 | 10/26 | **사장님 폐기 줄이기 — 진열대 임박 상품 점검** | 임박 목록, 발주 관리, 가격표 | 매장 |
| 4 | 11/2 | **가족·직원과 같이 보는 유통기한** (팀 공유) + 1~3주 숫자로 방향 조정 | 가족·팀 공유 | 가정+매장 |

※ 다음 앱 업데이트(v31)가 스토어에 공개되면 2~3주차에 "해외 제품 날짜 순서 추천", "중국 제품 제조일+기간 계산"을 추가 주제로 쓴다. **v31 공개 전에는 홍보 글에 쓰지 않는다**(현재 스토어는 v30).

## 5. ASO 개선안 (제안만 — 제출은 사장님 결정)
현재 등록정보: `store-assets/store-listing-draft.md` (HANDOFF 기준 10/8 검토 제출 완료, 설명은 "지킴이→매니저"로 바뀜).

1. **짧은 설명** — 지금 문구의 "끝판왕"은 최상급 표현 소지. 제안(80자 이내):
   `바코드로 등록하고 유통기한 임박 알림 받기 — 가정·매장 소비기한 관리` (35자 안팎)
2. **키워드 후보** (설명 앞부분·첫 문단에 자연스럽게): 유통기한, 소비기한, 냉장고 관리, 식재료 관리, 유통기한 알림, 바코드, 재고 관리, 폐기 관리
   - 한국에서 2023년부터 식품 표시가 "소비기한"으로 바뀐 영향으로 "소비기한" 검색도 있음 → 이름에 이미 포함. 경쟁 앱 키워드는 **스토어에서 직접 검색해 확인 필요**(이번 실행은 네트워크 조사 없이 작성).
3. **스크린샷 문구**(7장 준비됨): 장마다 한 줄 설명 자막을 넣으면 전환에 유리. 예: 01 "임박 상품 한눈에" / 02 "D-day 배지로 바로 확인" / 05 "달력으로 보는 유통기한" / 06 "임박 재료로 레시피 추천" / 07 "가정용·매장용 모드 선택".
4. **전체 설명 첫 3줄**에 "누구에게 무엇을 해 주는지"를 넣기(현재는 질문 한 줄로 시작).
5. 스토어 등록정보의 "AI 생성 애셋" 표시는 유지.
6. 평점 요청: 앱 사용이 익숙해진 시점(예: 상품 10개 등록 후)에 한 번만 묻는 방식은 앱 변경이 필요하므로 **개발 제안**으로만 기록(코드 수정 안 함).

## 6. 이벤트 (제안 — 발급은 사장님 결정, 현재 앱에 코드 입력 기능 없음)
`docs/monetization.md` 1-5에 "단톡방 무료 이용 이벤트"(매장용 6개월 무료, 100개)가 확정돼 있으나 **결제·코드 입력 기능이 아직 앱에 없고 v31 이후 구현 예정**. 따라서 이번 주 글에는 이벤트를 **언급하지 않는다**. 구현·배포 후 3주차(매장 주제)에 맞춰 안내 글을 만든다.
