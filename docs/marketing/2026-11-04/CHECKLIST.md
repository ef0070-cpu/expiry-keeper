# wk1116 게시 체크리스트 (11/17~11/21, 캠페인 `wk1116`)

주제: 발주 넣기 전에 보는 것들 — A 검색발주 / B 발주 전에 남은 날짜 먼저 / C 월말에 돌아보는 소진·폐기 기록. 가격·혜택 약속 없음. **가격표는 이번 묶음에서 제외**(프로덕션 출시 근거 없음, 다음 묶음 후보).

> **일정**: 10/28 묶음(wk1102)이 11/16(월)·18(수)·20(금)이라 하루씩 어긋나게 화·목·토로 잡았다. 훅 B는 같은 요일 다음 주(11/24·26·28) 16:00에 별도 게시한다(PLAN 8-1 훅 비교). 훅 B 게시 항목은 아직 `publish.json`에 없다.
> `approved`는 사장님만 true로 바꾼다(에이전트는 변경 금지). 지금은 false.
> 블로그·쇼츠·커뮤니티는 이번 요청 범위 밖이라 만들지 않았다.

## 2. 게시 전 확인 (한 번만)

- [ ] **스토어판 앱**(테스트 계정·매장 모드, 개발용 빌드 아님)에서 직접 확인. 확인자·날짜: ________ (R-4, 확인 전 게시 금지)
  - [ ] **검색발주**: 상품 이름 검색 → 담기 → 발주 목록에 쌓임 (v31 프로덕션 승격 미확인, 검색발주 화면은 v33에서 크게 바뀜)
  - [ ] 상품 목록의 **날짜 배지**(7일 이하 빨강, 30일 이하 주황, 31일 이상 초록)가 보이는가
  - [ ] **발주 관리**에 담기가 되는가
  - [ ] **월별 통계**에 월 행마다 '소진 n · 폐기 n' 글자와 막대·범례가 있는가
  - [ ] 위가 카드와 다르면 해당 카드(A 3·4, B 2·3, C 3)를 스토어판 모양으로 고친 뒤 게시
- [ ] 카드의 앱 화면은 **CSS로 그린 예시 화면**이다. 캡처(`shots/w1116-*.jpg`)를 찍으면 교체할 수 있다. 라벨 "예시 화면 · 실제와 다를 수 있어요"가 예시 카드마다 붙어 있는가
- [ ] 스레드 입력창에서 **글자 수 500자 이내**와 링크 1개, 태그 1개를 확인(공개 글은 올린 뒤 15분 안에만 수정 가능)
- [ ] 인스타 캡션에 주소가 없고 해시태그가 5개 이하인가
- [ ] 발행 문구에 가격·"무료"·"줄여 준다"·"알림이 직원에게 간다" 같은 표현이 없는가
- [ ] `node scripts/publish-promo.mjs`(미리보기)가 전부 ✓인지 확인한 뒤 승인 (카드가 GitHub에 푸시돼 있어야 Meta가 가져감)
- [ ] 10/28 묶음(11/16·18·20)과 같은 시각에 겹치지 않는지 `publish.json` 확인
