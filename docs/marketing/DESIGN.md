# 홍보 이미지 디자인 가이드 (ek-design)

기준 원본: `store-assets/play-icon-512.png`, `store-assets/feature-graphic-1024x500.png` (스토어에 올린 마스코트 로봇 스타일)

## 색 (피처 그래픽에서 추출)
| 용도 | 값 |
|---|---|
| 배경(복숭아 베이지) | `#FBE5D0` |
| 본문·제목(진한 청록 먹색) | `#24363B` |
| 포인트(민트 그린) | `#5FB894` (밝은 `#CDEBDD`) |
| 강조(임박·D-day 느낌의 코랄) | `#E4604F` |
| 카드 바탕 | `#FFFFFF` |

## 글
- 제목 굵게 64~92px, 본문 40~46px, 줄 간격 1.4. 한 장에 메시지 하나.
- 서버 글꼴은 WenQuanYi Zen Hei뿐(웹 글꼴 다운로드 불가) → 굵기는 `-webkit-text-stroke`로 보정. 최종본은 사장님이 캔바(Pretendard·나눔스퀘어 등)로 다듬기.

## 구성
- 인스타 카드: 1080×1350. 좌상단 앱 이름(작게), 중앙 메시지, 하단 마스코트 또는 앱 화면(둥근 모서리 + 그림자).
- 앱 화면은 상단 알림줄 포함 그대로 쓰되 개인정보·옛 이름이 없는 캡처만.
- 마스코트는 피처 그래픽에서 잘라 쓴다(스토어 등록 애셋). 새 캐릭터를 그리지 않는다.
