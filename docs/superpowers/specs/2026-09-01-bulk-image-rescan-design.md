# 사진 일괄 재검색 (설정 화면) — 설계

## 배경

`product-form.tsx`의 "웹에서 이미지 찾기"를 상품명 우선 검색에서 바코드 우선 검색으로 개선했다(커밋 `1b81898`). 이미 등록된 상품들은 예전 방식(상품명만)으로 찾은 사진이 들어있을 수 있어, 새 로직으로 다시 일괄 검색해 반영하는 기능을 원함.

## 범위

- `src/app/settings.tsx`: "기능" 섹션에 "사진 일괄 재검색" 항목 추가(클라우드 모드일 때만 노출 — `hasImageSearchKeys()`가 클라우드 모드를 요구하는 것과 동일한 조건)

## 대상 판정 규칙

`Product.imageUri`는 사진 출처를 구분하는 별도 필드가 없지만, 값 자체로 구분 가능하다:
- 카메라/앨범에서 직접 고른 사진 → 로컬 파일 경로(`file://` 등, `http`로 시작하지 않음)
- 웹 검색/바코드 조회로 찾은 사진 → 원격 URL(`http`로 시작)

대상 = `barcode`가 있고(공백 아님) **AND** (`imageUri`가 없음 **OR** `imageUri`가 `http`로 시작).

이 규칙으로 사용자가 직접 등록한 사진은 절대 덮어쓰지 않는다. `listProducts()`가 이미 현재 앱 모드(가정용/소매용) 기준으로 상품을 필터링해 반환하므로 별도 모드 필터링은 불필요.

## 동작 흐름

1. "사진 일괄 재검색" 항목 탭 → 대상 개수를 미리 계산해 확인 팝업 표시: "N개 상품을 대상으로 새 로직으로 사진을 다시 찾습니다. 직접 등록한 사진은 바뀌지 않습니다. 진행할까요?"
   - 대상 0개면 팝업 없이 바로 "재검색할 상품이 없습니다" 안내만 표시하고 종료
2. "진행" 선택 → 대상 상품을 하나씩 순서대로 처리(동시 요청 아님 — 서버 API 과부하 방지):
   - `lookupBarcode(barcode)` 호출
   - 결과 `imageUrl`이 있고 기존 `imageUri`와 다르면 `saveProduct({ ...product, imageUri: result.imageUrl })` 호출, 업데이트 카운트 증가
   - 다음 상품 처리 전 250ms 대기
3. 처리 중에는 버튼이 진행 표시로 바뀜: "사진 재검색 중... {완료}/{전체}" (회원탈퇴 처리 중 표시와 동일한 스타일 — `ActivityIndicator` + 텍스트)
4. 전부 끝나면 "{전체}개 중 {업데이트}개 사진이 업데이트됐습니다" 팝업
5. 도중 에러(네트워크 등) 발생 시 "재검색 실패" 팝업으로 중단하고 진행 상태 초기화

## 컴포넌트 변경 범위 (`src/app/settings.tsx`)

- import 추가: `listProducts, saveProduct` (`@/lib/repo`), `lookupBarcode` (`@/lib/barcode-lookup`)
- state 추가: `rescanning: boolean`, `rescanProgress: { done: number; total: number } | null`
- 함수 `rescanImages()`: 위 동작 흐름을 구현하는 `Alert.alert` 기반 확인 + 순차 처리 루프
- "기능" 섹션 안, `isCloudMode` 조건부로 항목 렌더 — `rescanning`이면 진행 표시, 아니면 `LinkRow`(아이콘은 기존 `product-form.tsx`에서 이미 쓰는 `image-search-outline` 재사용)

## 영향 없음

- 발주(order) 관련 화면·크라우드소싱 카탈로그 파이프라인과 무관 — 별도 기능.
- `product-form.tsx`의 "웹에서 이미지 찾기"(단건, 수동) 로직은 그대로 재사용만 하고 변경하지 않음.

## 테스트

테스트 프레임워크 없음 — `npx tsc --noEmit` + 수동 QA:

1. 바코드 있고 사진 없는 상품 하나 준비 → 재검색 실행 → 사진이 채워지는지 확인
2. 바코드 있고 `http` 이미지가 이미 있는 상품 → 재검색 후 이미지가 바뀌거나(새로 찾은 게 다르면) 그대로인지(같으면) 확인
3. 카메라로 직접 찍은 사진(로컬 경로)이 있는 상품 → 재검색 후에도 사진이 그대로인지(대상에서 제외됐는지) 확인
4. 바코드 없는 상품 → 대상에서 제외되는지 확인(재검색해도 안 건드림)
5. 대상 상품이 하나도 없는 상태에서 버튼 탭 → "재검색할 상품이 없습니다" 안내만 뜨는지 확인
6. 진행 중 화면에 "N/M" 카운트가 올라가는지, 끝나면 요약 팝업이 정확한 숫자로 뜨는지 확인
