# 발주 상품 초기화 (Reset All Order Products)

## 배경

발주관리(`검색발주`) 화면에 등록된 발주 상품을 통째로 지우고 처음부터 다시 등록하고 싶을 때가
있다(예: 잘못된 카탈로그로 시작해서 새로 정리하고 싶을 때). 현재는 상품을 하나씩 길게 눌러
삭제하는 방법뿐이라 388종 같은 대량 카탈로그를 비우기 번거롭다.

파괴적이고 되돌릴 수 없는 동작이므로, 실수로 눌러서 전체 데이터를 잃는 일을 막기 위해
일반적인 확인창(예/아니오)보다 강한 확인 절차(정확한 문구 재입력)를 요구한다.

## 범위

- **비우는 대상**: 카탈로그에 등록된 발주 상품 전체(이름·가격·바코드·카테고리 등). 기존
  `deleteOrderProduct`와 동일한 방식으로 처리해 클라우드 동기화 때 되살아나지 않게 한다.
- **같이 비워지는 것**: 장바구니(삭제되는 상품을 참조하고 있으므로).
- **범위 밖(안 건드림)**: 매장 목록, 냉동고 구역/진열 배치(구역 자체와 구역 이름은 남음 —
  다만 배정된 상품이 사라지므로 빠른발주 그리드에는 더 이상 안 보임), 카테고리 목록.
- 초기화 후에는 기존에 있던 "기본 상품 불러오기(아이스크림 388종)" 버튼(빈 목록일 때 노출)으로
  다시 채울 수 있다 — 별도 기능 추가 불필요.

## 데이터 계층 변경

`src/lib/order-repo.ts`에 `clearAllOrderProducts(): Promise<void>` 추가.

- 기존 `deleteOrderProduct(id)`와 같은 tombstone 방식(삭제된 바코드는
  `REMOVED_BARCODES_KEY`에, 삭제된 상품 id는 `DELETED_ORDER_PRODUCT_IDS_KEY`에 기록)을
  전체 상품에 한 번에 적용 — `deleteOrderProduct`를 388번 반복 호출하면 매번 전체 목록을
  다시 읽고 쓰는 비용이 커지므로(O(n²)), 한 번의 읽기 + 한 번의 쓰기로 처리한다.
- 상품 목록을 빈 배열로 저장(`writeOrderProducts([])`).
- 장바구니를 비움(`writeOrderCart({})`) — 남아있던 카트 항목은 전부 방금 삭제된 상품을
  참조하므로 그대로 둘 이유가 없다.
- 각 상품에 대해 `deleteOrderProductCloud(id)`를 best-effort로 호출(실패해도 무시, 기존
  `deleteOrderProduct`와 동일한 처리).

## UI 변경 (`src/app/order.tsx`)

- 헤더(`headerRight`)에 아이콘 버튼 추가(바코드 스캔 아이콘 왼쪽). 등록된 상품이 0건이면
  버튼을 숨긴다(지울 게 없을 때 노출할 이유가 없음).
- 탭하면 확인 모달(`ResetProductsModal`, 다른 모달들과 동일한 스타일 — `bg-ink/40` 배경 +
  `rounded-2xl bg-paper p-4` 카드)을 연다:
  - 경고 문구: "등록된 발주 상품 N건이 모두 삭제됩니다. 되돌릴 수 없어요."
  - 안내: "계속하려면 아래에 '초기화'를 입력하세요."
  - `TextInput` — 입력값이 정확히 `초기화`와 문자 그대로 일치해야 확인 버튼이 활성화됨.
  - "초기화" 버튼(비활성 상태는 흐리게 표시) / "취소" 버튼.
- 확인 시: `clearAllOrderProducts()` 호출 → `load()`로 목록/뱃지 새로고침 → 모달 닫고 입력값
  초기화 → 토스트로 "상품을 모두 초기화했어요" 표시(기존 `toastMessage` 상태 재사용).

## 에러 처리

- 별도 항목 없음 — 로컬 저장(AsyncStorage) 실패는 이 앱의 다른 쓰기 작업과 동일하게 예외가
  올라오는 대로 두고, 클라우드 삭제는 항상 best-effort(`.catch(() => {})`)로 처리한다(기존
  코드베이스 관례와 동일).

## 테스트

수동 확인: 상품 여러 건 등록 → 헤더 아이콘으로 초기화 모달 열기 → 오타 입력 시 버튼
비활성 확인 → "초기화" 정확히 입력 후 버튼 활성화 → 확인 시 목록이 빈 상태로 바뀌고
"기본 상품 불러오기" 버튼이 다시 노출되는지 확인.
